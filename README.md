# Super Calculator

آلة حاسبة علمية متقدمة تعمل بالكامل داخل المتصفح، بدون خادم وبدون حساب.

## المزايا
- العمليات الأساسية والأقواس والنسب المئوية
- sin / cos / tan ونسخها العكسية
- DEG / RAD
- log و ln و √
- الأسس والجذور والعاملي x!
- π و e و ANS
- ذاكرة MC / MR / M+ / M−
- سجل محفوظ محليًا
- نسخ النتيجة
- الوضع الداكن والفاتح
- دعم لوحة المفاتيح
- متجاوبة مع الهاتف والكمبيوتر

## التشغيل
افتح `index.html` مباشرة، أو فعّل GitHub Pages من:
**Settings → Pages → Deploy from a branch → main → / (root)**

بعدها ستحصل على رابط ويب تستطيع استخدام الآلة الحاسبة منه على الهاتف أو الكمبيوتر.
